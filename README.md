# Personalized Travel Itinerary Planner

A beginner-friendly Generative AI capstone project. Travelers share preferences, then the app generates a personalized day-by-day itinerary with attraction, restaurant, accommodation, and transportation ideas. Users can save, edit, and regenerate plans.

## Planned technologies

- **Frontend:** React
- **Backend:** Python FastAPI
- **Database and authentication:** Supabase
- **Generative AI:** Google Cloud AI

These services are **not connected yet**. This repository is a project skeleton only.

## Project structure

```text
frontend/    React app (pages, components, API calls)
backend/     FastAPI app (routes, schemas, services)
```

## Planned features

- Collect travel preferences
- Generate personalized day-by-day itineraries
- Recommend attractions, restaurants, accommodations, and transportation
- Save, edit, and regenerate itineraries

## Getting started (later)

Packages are **not installed yet**. After you approve setup:

1. Create a Python virtual environment in `backend/` and install from `requirements.txt`
2. Install frontend packages with npm inside `frontend/`
3. Copy `.env.example` files to `.env` and fill in your own keys locally (never commit `.env`)
4. Run FastAPI, then the React app

Git is also not required for this skeleton. You can install Git later if you want version control.

## Environment files

- `frontend/.env.example` — frontend placeholder names
- `backend/.env.example` — backend placeholder names

Do not put real keys or passwords in those files.
